Privacy Policy

Last updated: November 18, 2026

This policy covers NoBrick Autopost (the "app"), an automated tool operated by No Brick Left Behind that generates brick-breaker simulation videos and uploads them to the channel's own accounts.

Who uses the app

The app is used only by its operator, to post to the operator's own YouTube channel (@NoBrickLB) and X account (@NoBrickLB). It is not offered to the public, and no one else can sign in to it.

What data the app accesses

  • YouTube: the app uses the YouTube API Services with the youtube.upload permission, only to upload videos it has generated to the operator's own channel and set their title, description, tags and privacy status.
  • X: the app uses the X API only to upload videos and publish posts on the operator's own account.
  • The app does not read, collect, store or share any information about viewers, subscribers or other users, and it does not access any other data in the connected accounts.

How credentials are stored

The access credentials (OAuth tokens and API keys) for the operator's own accounts are stored as encrypted secrets in a private GitHub repository and are used only when the app uploads a video. They are never sold, shared or used for any other purpose.

Cookies and tracking

This website does not use cookies, analytics or tracking.

Google and YouTube

The app uses YouTube API Services. By using YouTube you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. The operator can revoke the app's access at any time from the Google security settings page.

Deleting data

Because the app stores no user data, there is nothing to delete for viewers. The operator can remove the app's stored credentials at any time by deleting them from the repository and revoking access as described above.

Changes

If this policy changes, the updated version will be posted on this page with a new date.

Contact

Questions about this policy can be sent by direct message to @NoBrickLB on X.
